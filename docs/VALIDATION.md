# 原型验证记录

日期：2026-10-26。以下是已执行结果，不表示所有 Android 版本或第三方服务均兼容。

## 0.1.1

- 开发 APK、测试 APK 构建通过，lint 无错误。14 项核心测试与 3 项显式启用的真实网络测试通过，天气接口已验证返回日出与日落。
- 新增北京时间跨日选取、日出日落插值、缺测、分段间隙与临近行程事件的核心测试。
- 原生测试更新为路线页规划与一键跳转天气页，新增隔离存储的地图启用/关闭/删除/旧版迁移检查，以及新 ViewModel 恢复实际保存状态检查，共 9 项。测试 APK 已编译，本次未执行真机测试：用户手机已离开开发网络，选择手动安装。
- 底图启用状态保存与迁移、页面流程和日出日落视觉效果仍需本次安装后实测。覆盖安装保留既有 Key 和收藏；不要卸载旧版或清除数据。

手动验收：覆盖安装后检查底图是否自动恢复；关闭底图并重启应保持关闭；再次验证启用后重启应恢复。路线页导入演示，修改出发时间、均速及休息，点击查询，应跳到天气页显示天气地图和日出日落；返回路线页应保留计划且地图为普通轨迹，修改计划后旧天气应清除。选择临近日落或日出的出发时间可检查途中的事件卡片；行程不跨事件时仍有起终点与各采样点的日出日落时间。

## 0.1.0 历史记录

- APK 构建成功；JVM 核心测试 12 项、显式启用的联网测试 3 项通过；lint 无错误。
- Android 16 / API 36 实体设备安装、冷启动成功。
- connectedDebugAndroidTest 的 7 项 Compose 原生测试全部通过，0 跳过、0 失败。覆盖演示、规划页面、非法分享地址保持原轨迹、收藏完整轨迹持久化、真实包名和签名信息、非法地图 Key、顽鹿与行者公开路线导入，以及沿途天气匹配。一次完整 Gradle 调用（含编译、安装、测试）约 2 分钟，不能当作纯测试耗时或识图加速比。
