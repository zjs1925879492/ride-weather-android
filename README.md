# 沿途 · 骑行天气 Android

原生安卓骑行天气应用，计划将 [网页版](https://github.com/zjs1925879492/ride-weather) 的路线导入、沿途天气、风向分析和收藏功能迁移到手机。

**状态：项目初始化，尚无可运行的 Android 应用或 APK。**

## 产品约定

- 使用 Kotlin 和 Jetpack Compose 开发原生界面。
- 路线解析、坐标转换、到达时间、天气匹配和收藏管理在设备上完成。
- 手机直接请求第三方路线、天气、地图和地名服务；运行时不依赖本项目的云端后端。
- 允许用户填写自己的天地图 Key；保存在设备中，不上传至项目服务器。
- 缓存已有数据以支持弱网使用；刷新天气、获取分享路线及在线底图仍需联网。
- 不内置用户密钥，不公开签名私钥，不加入未经说明的统计或数据上传。

## 首轮验证

1. 最小原生应用可以构建、安装和启动。
2. 显示真实安装包的包名、签名证书 SHA-1 / SHA-256，支持复制。
3. 用户填写天地图 Key 后加载底图，验证更换 Key 和重启持久性。
4. 验证天地图跨账户申请相同应用身份的限制、适用 Key 类型及鉴权方式。
5. 真机直连顽鹿 / 行者公开数据，验证本地转换；需要登录或拒绝访问时停止并提示导入 GPX。

以上验证尚未完成，不承诺第三方接口永久可用。
