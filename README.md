# 沿途 · 骑行天气 Android

Kotlin + Jetpack Compose 原生应用。状态：0.1.8 开发原型，已提供仅 arm64 的优化测试 APK；本次地图标注版本尚待真机验收。尚未完成网页版全部功能迁移。

## 已实现

- 本地 GPX 导入、导出，保留分段、已有海拔与路标；内置合成演示轨迹。
- 手机直接导入顽鹿、行者、iGPSPORT 国内站公开路线；顽鹿可显式选择来源坐标系，iGPSPORT 保留原始 WGS84 坐标和可用高程。
- 按速度、出发时间、休息时间与采样间隔计算到达时间，匹配 Open-Meteo 天气，计算迎风分量并为路线着色。
- 路线页完成导入、普通轨迹预览与出发规划；点击查询后跳到天气页，对照天气分区地图、采样点天气和日出日落时间线。
- 日出日落按网页版行程事件逻辑提醒：只在预计途中发生，或出发前 / 结束后 30 分钟内发生时插入事件卡片。不显示起终点汇总，也不在每个采样点显示日出日落。
- 天气卡片突出里程，日期时间采用小字；降水和风况分两列显示，不展示序号、经纬度和匹配预报时间。
- 天气地图增加采样点里程、沿线方向箭头及日出日落事件标记；标签避让重叠，优先显示事件和起终点里程。标记图像使用本机字体绘制，无额外在线字体请求。
- 天地图启用状态随加密 Key 恢复；手动关闭也会记住，删除 Key 后不会自动启用。
- SQLite 收藏索引、私有文件保存轨迹；天气短期缓存与请求失败回退。
- 原生 MapLibre 地图，没有底图 Key 时仍可显示轨迹。用户天地图 Key 经 AndroidKeyStore 加密保存，可删除。

路线解析、坐标转换、到达时间与收藏在手机处理。运行时不依赖本项目后端；新天气、公开路线与在线底图仍需请求第三方服务。

天地图当前接入 **WMTS 网络服务**，没有使用天地图 Android SDK；应申请与该服务匹配的 Key 和权限，不能据此推断 Android SDK 的签名授权规则。尚未使用有效用户 Key 完成底图、更换 Key 与重启恢复验收，也未验证跨账户申请限制。不承诺第三方接口永久可用。

## 当前限制

沿途地名、收藏批量备份与撤销等功能尚未迁移；原型没有实时定位、导航或离线地图包。日出日落来自采样点天文时间，途中的事件位置通过预计经过时间插值，不代表地形遮挡下实际光照。公开路线遇到拒绝授权时停止，可改为本地 GPX。顽鹿默认坐标系是待进一步确认的来源假设，导入时可手动选择。

## 开发与验证

iGPSPORT 支持 `https://analyse.zh.igpsport.com/new/my/road/book/share?routeId=70714&language=zh-Hans` 及 `/new/road/book/share` 路径。手机匿名直连官方公开接口，导入后可收藏、查询天气和导出 GPX。需要登录或没有公开权限的路书可从原平台导出 GPX 后导入。输入限唯一正整数 routeId，响应限 8 MB、150,000 点及 2,000 途经点；接口变更可能影响可用性。

见 [构建与真机测试](docs/DEVELOPMENT.md) 和 [验证记录](docs/VALIDATION.md)。包名为 `io.github.zjs1925879492.rideweather`。当前 APK 使用开发签名，正式发布前需单独管理发布签名。

面向 arm64-v8a / Android 8.0 及以上设备，不再包含 32 位 ARM 与 x86 库。`preview` 构建启用 R8 和资源裁剪，关闭调试，沿用现有开发签名方便覆盖测试；正式发布签名另行配置。当前精简包 14,483,824 字节，上一版通用开发包 61,620,824 字节。Release 暂停公开发布，先完成优化包验收。
