# 沿途 · 骑行天气 Android

Kotlin + Jetpack Compose 原生应用。状态：0.1.0 开发原型，已有可构建 APK，Android 16 真机原生自动化测试通过。尚未完成网页版全部功能迁移。

## 已实现

- 本地 GPX 导入、导出，保留分段、已有海拔与路标；内置合成演示轨迹。
- 手机直接导入顽鹿、行者公开路线；显式选择来源坐标系，本地转换。
- 按速度、出发时间、休息时间与采样间隔计算到达时间，匹配 Open-Meteo 天气，计算迎风分量并为路线着色。
- SQLite 收藏索引、私有文件保存轨迹；天气短期缓存与请求失败回退。
- 原生 MapLibre 地图，没有底图 Key 时仍可显示轨迹。用户天地图 Key 经 AndroidKeyStore 加密保存，可删除。
- 显示实际安装包的包名、签名 SHA-1 / SHA-256，支持复制。

路线解析、坐标转换、到达时间与收藏在手机处理。运行时不依赖本项目后端；新天气、公开路线与在线底图仍需请求第三方服务。

天地图当前接入 **WMTS 网络服务**，没有使用天地图 Android SDK；应申请与该服务匹配的 Key 和权限，不能据此推断 Android SDK 的签名授权规则。尚未使用有效用户 Key 完成底图、更换 Key 与重启恢复验收，也未验证跨账户申请限制。不承诺第三方接口永久可用。

## 当前限制

沿途地名、日出日落时间线、收藏批量备份与撤销等功能尚未迁移；原型没有实时定位、导航或离线地图包。公开路线遇到拒绝授权时停止，可改为本地 GPX。顽鹿默认坐标系是待进一步确认的来源假设，导入时可手动选择。
